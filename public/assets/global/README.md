# Global Style Assets

Store reusable paper textures, photographed tape, brush marks, and non-semantic doodles here. Recipe-specific imagery belongs directly in the corresponding folder under `src/content/recipes/`.

Current material assets:

- `paper-texture-v1.webp` — subtle seamless paper scan used by the page and printed-surface overlay
- `watercolor-wash-mask-v1.webp` — lossless neutral alpha mask recoloured in CSS for marker fields, notes, and grounding shadows

Generation prompts and processing are documented in [the global material texture note](../../../docs/prompts/global-material-textures.md).
